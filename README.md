# DH SpaH

Site comercial desenvolvido com Next.js, TypeScript e CSS responsivo.

## Abrir no VS Code

1. Extraia o arquivo ZIP.
2. Abra a pasta `dh-spah` no VS Code.
3. Abra o terminal do VS Code.
4. Execute `npm install`.
5. Execute `npm run dev`.
6. Abra o endereço exibido no terminal, normalmente `http://localhost:3000`.

## Páginas

- Início
- Produtos
- Experiência SPA
- Curso Vela Gruta
- Sobre
- Contato

Os links de WhatsApp e Instagram já estão configurados.
